# README Screenshot Sources

These PNGs are unchanged embedded images from the revised TokenWise project report.
They show recorded output; this documentation update did not rerun their prompts
or recreate measurements.

`tokenwise-icon.png` is a byte-identical copy of the existing extension icon,
not a captured result or a new report screenshot.

| File | Report figure | What it shows |
| --- | --- | --- |
| `antigravity-context.png` | Figure 12 | Retrieval acknowledgement and the beginning of a project summary. Visible waiting durations are not a controlled timing benchmark. |
| `repository-context.png` | Figure 17 | Session-expiry/revocation discovery: local source/packet counts, configured carbon estimates and file provenance. |

The two panels are different runs, not a matched WITH/WITHOUT experiment. Carbon
values are estimates, not measured provider emissions. Source counts are local
tokenizer values, not actual reported Antigravity billing usage.

The original report is not modified or bundled with these assets. No private CLI
logs, access credentials or captured evaluation answers are included.
