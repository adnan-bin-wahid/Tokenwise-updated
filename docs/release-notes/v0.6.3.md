# TokenWise 0.6.3: Inspect the Inputs to Pruning

This local development build makes three input scenarios inspectable:

- Repository discovery without an editor-selection anchor.
- Neural pruning of exactly the captured file or highlighted excerpt.
- A bounded earlier-user replay for a referring follow-up, explicitly labeled
  as replay rather than live Antigravity chat capture.

The result panel exposes the current task, inference objective, scope, history
source, thresholds, per-file pruning method, and JSON export. Selected-source
results include real mean line relevance and the decision mask. Preservation,
gap restoration, formatting, and later packing can affect final membership.

Native hooks retain at most three earlier current-topic user turns, within a
2,000-character combined bound. Explicit tasks reset the topic; new chats and
missing conversation IDs do not reuse another chat's intent. Stable rule/tool
fallback asks the agent to resolve references into a bounded, self-contained
query. The backend cannot inspect that path's raw chat history.

Prune Current File now always takes the whole file. Direct pruning uses the
registered managed URL and resource-scoped settings. Carbon estimates use the
backend's native source counts, without inventing counts for empty input.

The demonstration bundle contains four independent runnable projects with 28
tests. The teacher guide now prioritizes inputs, pruning decisions, and history
isolation. Literal all-code/selected/automatic packet comparisons remain optional
and their Selected baseline is unpruned, unlike direct selected-source pruning.

## Install or Upgrade

1. Install the local `tokenwise-vscode-0.6.3.vsix` through Install from VSIX.
2. Reload and run **TokenWise: Set Up Backend** to update the matching backend.
3. Re-run **Enable Automatic Context** in configured demo folders to refresh rules.
4. Warm with **Start Backend**, then run **Demonstrate Pruning Inputs**.

The previously published 0.6.2 assets are unchanged. These notes do not assert
that 0.6.3 has been uploaded to GitHub or an extension marketplace.
Windows is the tested local platform; native macOS/Linux and remote workspaces
are not certified. Carbon values are configured-scenario estimates, not measured
provider emissions. Generated transcript/native-hook verification is not a live
Antigravity cloud test, and this is not unrestricted cross-chat memory.
