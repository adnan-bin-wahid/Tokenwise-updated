# TokenWise 0.6.8 - Windows Beta

Earlier user requirements can now inform retrieval even when the latest request
is self-contained. Memory remains bounded and inspectable, not a full-chat dump.

## Upgrade

1. Install `tokenwise-vscode-0.6.8.vsix` through **Extensions > ... > Install from
   VSIX...**, then reload Antigravity.
2. Finish active TokenWise requests, run **TokenWise: Set Up Backend**, and install
   the matching backend. Verified downloads are reusable; failed steps are retryable.
3. Open your trusted local Python folder and run **TokenWise: Enable Automatic
   Context** again to update the owned rules and launchers. Customized files are
   preserved; resolve any preservation warning before testing the new transport.
4. Start a new chat. Ask `Explain account lockout. Do not modify any files.`,
   then `Use bullet points.`, then `Explain account lockout boundary tests.`
5. Run **TokenWise: Show Automatic Context**, expand **Conversation memory**, and
   inspect earlier references, selection reasons, omissions and the current objective.

Use the ZIP's `demonstration/tokenwise_demo` folder for the example. The ZIP and
installer include the concise `demonstration2.md` guide; **Open Validation Guide**
links to it. Ordinary users need no Git clone, Node.js, compilation or F5.

## Behavior and Limits

- Selection considers up to 32 bounded earlier user messages and selects at most
  eight messages and 4000 reference characters. Native transcript scanning uses
  the existing 16 MiB tail bound and at most 64 earlier qualifying turns before
  candidate normalization. No other chat's `latest.json` is used as memory.
- Topic matching, follow-up recognition and constraint replacement are lexical
  English heuristics. Recognized active requirements are preserved, but arbitrary
  coreference, paraphrases and conflicts can still need clarification. The task
  summary is an extract, not a generated semantic summary.
- Native capture accepts verified conversation IDs or chat-scoped paths; it falls
  back to this chat's recorded state when older transcript identity is unavailable.
- Rule fallback passes separate earlier user strings selected by Antigravity.
  The panel labels this agent-supplied reference, not independently verified capture.
  Changing only the installed extension does not rewrite existing workspace rules.
- Assistant/model replies, tool output and earlier injected packets are not treated
  as remembered facts. Repository evidence is retrieved fresh under the current snapshot.
- The outgoing reference block uses at most 384 tokens and one quarter of the
  packet budget, with evidence space reserved. It may be compact or omitted;
  the panel exposes exact status/text. Retrieval can still use the bounded hint.
- Set `"conversation_memory": false` in `.agents/tokenwise.json` to disable automatic
  memory transport and use. `latest.json` remains the latest activity report;
  it is not a permanent transcript archive. Local state/exports may contain user
  requirements, so review them before sharing.

Automatic packet comparison, reported CLI-usage import, response guidance and
carbon reporting remain included. Packet counts are not observed IDE usage;
carbon is a configured estimate. This release does not claim a completed live
Antigravity quality study or native macOS/Linux installation verification.
