# TokenWise 0.6.2: Controlled Classroom Comparisons

This Windows-tested beta adds **TokenWise: Compare Context Strategies** for the same
saved Python repository and task: all indexed Python source, one manual
selection, and automatic retrieval without hidden editor-selection hints.
The view includes exact complete-packet counts, optional fixed-scenario
energy/CO2 estimates, copy controls, and a JSON export. Baselines are size
limited and fail visibly instead of silently truncating all-code exports.

Three independent standard-library demo repositories and `demonstation.md`
provide prompts, executable expected behavior, fresh-chat quality evaluation,
conversation-isolation experiments, and a rehearsal script. Automated exports
do not claim to grade cloud-agent answers.

Recognized native follow-ups may use a bounded prior user topic scoped to
workspace/conversation ID. New chats do not inherit another chat's topic;
explicit tasks replace it. Missing conversation IDs disable reuse. Fallback
rules resolve references from current-chat user intent or ask for clarification.

Install the matching VSIX, reload, run **TokenWise: Set Up Backend**, and
re-enable configured demo workspaces to get the updated rules/backend.
Carbon values remain approximate configured-scenario predictions, not
measured Antigravity emissions. This build does not implement cross-chat memory.

Short matched source bodies are retained without additional model passes.
Configuration dependencies receive reserved candidate slots to avoid losing
the constants needed to explain behavior when tests rank above implementation.

## Install or Upgrade

1. Download `tokenwise-vscode-0.6.2.vsix` from the release assets.
2. In Antigravity choose **Extensions > ... > Install from VSIX...**, then reload.
3. Run **TokenWise: Set Up Backend** to install/update the matching backend.
   Python 3.12 (64-bit) and initial download access are required. Verified model
   downloads are reused on upgrade; do not uninstall just to update.
4. Open your local Python repository and run **TokenWise: Enable Automatic
   Context**. Re-run it in existing workspaces to refresh the follow-up rules.
5. Start a new agent chat and enter a normal repository prompt.

Download `TokenWise-0.6.2.zip` for the installer plus three independent demo
projects, `demonstation.md`, a results worksheet, and licenses. This is not
GitHub's automatically generated source-code ZIP. Open one demo leaf folder
at a time; do not enable automatic context in `demonstration/baseline_lab`.

The detailed guide covers all-code/manual/automatic comparisons and same-chat
follow-ups versus new-chat isolation. Carbon values are configured predictions;
automated source-marker checks are not semantic agent-answer grading.

macOS/Linux setup is included but not natively verified. Remote and virtual
workspaces remain unsupported. Marketplace publishing is separate.
