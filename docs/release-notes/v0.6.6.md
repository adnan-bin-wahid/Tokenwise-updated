# TokenWise 0.6.6 - Windows Beta

Task-aware prompt engineering now accompanies the repository context TokenWise
sends to Antigravity. Earlier published releases and installers remain unchanged.

## What Changed

- Versioned response guidance for explanations, bug fixes, refactoring, features,
  tests, and repository overviews. It asks for file/symbol citations, grounded
  claims, honest uncertainty, and respect for the latest user constraints.
- The instruction block is separate from source excerpts, never authorizes edits,
  and never requests invented behavior or unexecuted test results.
- Guidance is default-on, capped at 160 TokenWise tokens and one quarter of the
  packet budget, and can fall back to compact instructions or be omitted when
  it cannot fit. Complete packet counts include the guidance.
- No additional LLM call. The same guidance is included in matched unpruned and
  pruned carbon baselines; cache identity includes its version and enabled state.
- Inspect profile, version, applied/disabled/budget-omitted status, format, tokens,
  and exact text through workspace results and exported JSON.
- Automatic retrieval uses `response_guidance` in `.agents/tokenwise.json`;
  manual repository/demo/comparison requests independently use the editor's
  **TokenWise > Enable Response Guidance** setting.
- Updated study and one-project teacher rehearsal are bundled in the VSIX and
  presentation ZIP, including an honest guided-versus-unguided evaluation protocol.

## Install or Upgrade

1. Download `tokenwise-vscode-0.6.6.vsix`, then choose **Extensions > ... > Install
   from VSIX...** in Antigravity. Select that file and reload the editor.
2. Finish active TokenWise prompts, then run **TokenWise: Set Up Backend** and
   approve **Install Backend**. An older running Python backend does not acquire
   this feature merely because the extension was upgraded. Verified model
   downloads can be reused; a failed setup step offers **Retry Failed Step**.
3. Open a trusted local Python repository. Run **TokenWise: Enable Automatic
   Context** to refresh rules and the backend link, then **TokenWise: Start Backend**.
4. Start a new Antigravity chat and ask: `Explain session expiry and its related
   tests. Do not modify any files.` Check the current tool output and
   **TokenWise: Show Automatic Context** for `Response guidance: v1 ... applied`.

No source clone, Git, Node.js, compilation, F5, or API key is needed for normal
installation. First-time backend setup still needs 64-bit Python 3.12, internet
access for dependencies/verified weights, and adequate storage. Customized checkout
processes are not stopped automatically; restart only a process you own or use
managed setup.

Download/extract `TokenWise-0.6.6.zip` for `demonstration/tokenwise_demo`,
`demonstation.md`, `study.md`, installer, licenses, and operational guides. Open
the demo folder itself, not the entire ZIP. **Open Demonstration Guide** opens
the bundled walkthrough from the installed extension.

## Verification and Limits

Local verification: 174 extension tests passed; 119 backend tests discovered,
118 passed and one Windows file-symlink privilege skip; twenty demo tests plus
its deterministic application check passed. Prompt-guidance regressions cover
both API routes, both automatic transports, strict booleans, cache separation,
exports, and offline complete-packet checks with the bundled real tokenizer.

HTTP/pruning contract tests use reference model doubles. No new live Antigravity
answer-quality study or real-weight inference/CO2 benchmark is claimed by this
release. Guidance is designed to improve answer reliability, not proven to do so
for every task. Source-only neural pruning remains an excerpt workflow.

This remains a Windows-tested beta for trusted local Python folders. Native
macOS/Linux validation is pending. CO2 is a configured-scenario estimate, not
measured cloud emissions or net energy savings. Chat hints are bounded, scoped
user intent, not permanent memory or cross-chat transcript capture. Small budgets
may omit guidance; older reports can show `not reported` until a backend upgrade
and fresh retrieval. Existing user rules/settings are preserved during setup.
