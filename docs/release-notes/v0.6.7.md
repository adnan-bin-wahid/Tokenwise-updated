# TokenWise 0.6.7 - Windows Beta

Automatic packet comparisons and a practical validation/comparison walkthrough
are now included in the installer. Earlier published releases remain unchanged.

## Install or Upgrade

1. Download `tokenwise-vscode-0.6.7.vsix`. In Antigravity choose **Extensions > ...
   > Install from VSIX...**, select it, then reload the editor.
2. Finish active TokenWise prompts. Run **TokenWise: Set Up Backend** and approve
   **Install Backend** to load the matching endpoint and code. Verified downloads
   can be reused; a failed step offers **Retry Failed Step**.
3. Open and trust a local Python folder. Run **TokenWise: Enable Automatic Context**.
4. Run **TokenWise: Configure Automatic Comparison**, choose **Enable automatic
   packet comparison**, then send your usual Antigravity prompt without selecting
   code. Inspect file lists, packet tokens, increases/reductions and JSON export.
5. Run **TokenWise: Open Validation Guide** for the teacher's actual with/without
   experiment, fixed questions, answer rubrics and results worksheet.

No Git clone, Node.js, compilation or F5 is needed for ordinary installation.
First setup still requires 64-bit Python 3.12, disk space and internet access for
dependencies/model downloads. Download `TokenWise-0.6.7.zip` for the same VSIX,
one runnable `demonstration/tokenwise_demo` repository, `validation.md`,
`demonstation.md`, `study.md`, operational guides and checksums.

## What's Included

- Opt-in comparison after fresh automatic retrieval. It reuses the exact prepared
  packet without another pruning pass and requires no selected editor file.
- Snapshot reconciliation, bounded all-Python baseline, local packet and
  task-plus-packet counts, file lists, explicit increases or reductions, configured
  carbon predictions and JSON export. Limits: 200 Python files and 2 MiB of source.
- Enable, disable and retry actions. A changed saved snapshot needs a fresh
  prompt; a failed comparison does not block delivery of usable context.
- **Import Antigravity Usage Comparison** accepts two independent successful,
  fresh single-turn CLI JSON/stream-JSON logs. It preserves reported counters,
  durations, answers and deduplicated completed tool parameters, with JSON export.
- **Open Validation Guide** opens the bundled protocol directly. The pilot uses
  three tasks, three repetitions and two conditions: eighteen independent runs.

## Measurement Boundaries

Automatic comparisons measure locally prepared packets. The all-Python packet
is a hypothetical without-pruning baseline, not an observed native Antigravity
run without TokenWise. It does not reveal IDE model usage, every file read,
hidden instructions/history, caches, output or answer quality. Small projects
can show an increase; a lower packet count is not automatically a lower bill.

Imported usage belongs to the CLI runs supplied by the user, not private IDE
chat telemetry. Without/with labels do not independently verify task equality
or consumption of a TokenWise packet. Failed, resumed, zero-usage,
mixed-conversation, duplicate-session and differing reported-model pairs are
rejected; missing model/trace information is disclosed. No cloud A/B requests
are launched automatically and no answer-quality score is invented.

Carbon remains a configured inference scenario, not measured agent emissions
or net energy including local pruning. This is a Windows-tested beta for trusted
local Python folders; native macOS/Linux verification is pending.

## Verification

191 extension tests and 121 backend tests passed, with one additional backend
test skipped for Windows symlink privileges. The twenty demo tests and
deterministic app check passed. Eight desktop/narrow comparison views passed
browser layout and control checks with explicitly synthetic UI fixtures.
Details are recorded in `demonstration/VERIFICATION.md`. A new live Antigravity answer-quality or
real-weight pruning benchmark is not claimed by this release. Comparative
worksheets intentionally contain no fabricated trial outcomes.
