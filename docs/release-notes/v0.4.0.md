# TokenWise 0.4.0 - Windows Beta

Automatic, bounded Python repository context for Antigravity prompts. Open your
Python project, enable TokenWise once, and enter your normal prompt without
manually selecting files.

**This is a public beta. Windows installation/retrieval are tested; macOS/Linux
launchers are included but have not been verified on native machines.**

## Install in Antigravity

1. Install **64-bit Python 3.12** from [python.org](https://www.python.org/downloads/) if needed, then restart the IDE.
2. In **Extensions > ... > Install from VSIX...**, select `tokenwise-vscode-0.4.0.vsix` and reload the editor.
3. Open and trust your local Python repository.
4. Run **TokenWise: Enable Automatic Context**, choose **Install Managed Backend**, confirm setup, and wait for it to finish.
5. Confirm enabling this repository, start a **new Antigravity chat**, and enter your prompt.

No Git checkout, Node.js, compilation, F5, GPU, TokenWise API key, or manual file
selection is required. Your Antigravity model access/billing remain separate.
First setup downloads approximately **1.35 GB of verified model weights** plus
CPU dependencies; allow about **10 GB free disk space** and several minutes.

## What's New

- A private backend installer bundled with the extension; no checkout required.
- One shared backend for arbitrary local Python repositories.
- Verified/resumable model downloads, setup progress, cancellation, and retry.
- Setup diagnostics, backend warm-up, and a complete guide inside the editor.
- Preservation of unrelated workspace rules, hook handlers, and settings.
- Fixes for Antigravity's local storage URI and Windows paths with spaces.

## Support and Privacy

Run **TokenWise: Diagnose Setup** or inspect **Output > TokenWise Setup** if setup
fails. **TokenWise: Open Setup Guide** opens the complete instructions.

Retrieval runs locally; selected code then enters your normal Antigravity model
request and its provider's privacy policy. Stable Antigravity relies on the agent
following the workspace rule and approving the local command when required.
Remote/virtual workspaces are unsupported. Carbon estimates are approximate.

Read the [versioned usage guide](https://github.com/adnan-bin-wahid/Tokenwise-updated/blob/v0.4.0/README.md),
[changelog](https://github.com/adnan-bin-wahid/Tokenwise-updated/blob/v0.4.0/CHANGELOG.md),
and [third-party notices](https://github.com/adnan-bin-wahid/Tokenwise-updated/blob/v0.4.0/docs/THIRD-PARTY-NOTICES.md).
Report problems through [GitHub Issues](https://github.com/adnan-bin-wahid/Tokenwise-updated/issues)
with your OS, TokenWise version, and sanitized setup logs. Never share credentials,
private source excerpts, or `.tokenwise/latest.json` from a private repository.

## Validation

51 Node tests and 36 Python tests passed. Windows validation also included a
fresh managed environment, CPU model cold start, and bounded retrieval from two
external repositories. The installer test reused verified local weights; the
official HTTPS download endpoint/range response was checked separately, not a
full model redownload. No native macOS/Linux or cloud-agent test is claimed.
