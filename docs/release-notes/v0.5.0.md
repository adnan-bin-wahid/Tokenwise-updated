# TokenWise 0.5.0 - Windows Beta

This update adds automatic uninstall cleanup to TokenWise's local Python
repository-context extension for Antigravity.

Use the VSIX, not GitHub's source-code archive, for normal installation.

## Upgrade and Use

1. Install the new VSIX through **Extensions > ... > Install from VSIX...**.
2. **Reload the IDE once** so 0.5.0 registers existing storage and open repositories.
3. Existing complete backends can be reused. New users need **64-bit Python 3.12**,
   then **TokenWise: Enable Automatic Context > Install Managed Backend**.
4. Enter your usual prompt in a new Antigravity chat; no manual file selection.

Initial managed setup downloads about 1.35 GB of model weights plus dependencies.
Allow about 10 GB free disk space. TokenWise needs no separate API key or GPU.
Your Antigravity access/billing remain separate.

## Uninstall Cleanup

Finish active agent/setup commands, click **Uninstall**, and **fully restart the
IDE** when required. The editor invokes cleanup when removal completes, not
necessarily at the instant the button is clicked. Large deletions continue in a
self-contained background worker.

For normal managed installations, cleanup removes managed environments/model
downloads/private pip caches, verified owned backend/setup processes, tracked
workspace rules/launchers/hooks/configuration, context records, backend links,
TokenWise ignore additions/preferences, and its own tracking/temporary files.
Application source and unrelated settings/rules/handlers remain intact.

**TokenWise: Remove All Local Data** performs cleanup immediately and displays
any preservation/failure report before you uninstall.

For older 0.4.0 repositories, workspace-history discovery assists migration.
Open any old configured repository absent from that history once in 0.5.0 before
uninstalling. Keep its drive/folder available.

## Important Limits

This is a **Windows-tested beta**. macOS/Linux cleanup is included but not yet
verified on native systems. Remote/virtual workspace setup remains unsupported.

Customized/unrecognized files and malformed configuration are preserved and
reported. Cleanup does not delete pre-existing backend checkouts, Python itself,
other software's shared caches, downloaded installers, source-control history,
or editor/OS-owned history, logs, databases, and backups. It cannot guarantee
zero traces or delete inaccessible folders. Failed/partial cleanup retains a
small diagnostic registry/report rather than risking user data.

Retrieval runs locally; selected source still enters your normal Antigravity
model request and its provider's privacy policy. Stable Antigravity relies on
the agent following its workspace rule, not guaranteed native interception.

## Validation and Support

Release validation passed **81 extension tests and 36 Python tests**.

Read the [versioned README](https://github.com/adnan-bin-wahid/Tokenwise-updated/blob/v0.5.0/README.md),
[changelog](https://github.com/adnan-bin-wahid/Tokenwise-updated/blob/v0.5.0/CHANGELOG.md),
and [third-party notices](https://github.com/adnan-bin-wahid/Tokenwise-updated/blob/v0.5.0/docs/THIRD-PARTY-NOTICES.md).
Report problems through [GitHub Issues](https://github.com/adnan-bin-wahid/Tokenwise-updated/issues)
with sanitized logs and your OS/version. Do not share credentials or private
repository context.

Tests cover ownership, shared configuration, junctions, PID reuse, old workspace
discovery, retry inventory, command confirmation/trust/reporting, and worker
survival after extension deletion. Native Windows Antigravity uninstall
verification passed using an isolated IDE profile/extension directory, deferred
removal/restart, and a harmless private Python process. It confirmed removal of
the owned backend process, generated workspace integration, storage, and worker
while preserving application code and unrelated settings. It did not uninstall
the real user installation or test native macOS/Linux systems.
