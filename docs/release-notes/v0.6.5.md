# TokenWise 0.6.5 - Single-Project Demonstration

This version is prepared locally, not yet published as a GitHub release.

## What Changed

- One runnable `demonstration/tokenwise_demo` application replaces four projects.
- Account lockout, sessions, unrelated invoices/shipping, and activity reports
  provide useful positive and negative retrieval examples in the same workspace.
- Twenty deterministic standard-library tests define the expected behavior.
- The teacher guide includes a rehearsal checklist, exact commands and prompts,
  explanatory scripts, source/packed token distinctions, CO2 assumptions,
  same-chat/new-chat controls, packet comparisons, and troubleshooting.
- **TokenWise: Open Demonstration Guide** opens the bundled walkthrough.
- Packaging clears only its owned generated example directory before rebuilding,
  preventing old projects from leaking into the new VSIX.

## Install the Local Build

Use `tokenwise-vscode-0.6.5.vsix`, reload the editor, and run **TokenWise: Set Up
Backend** if an update is offered. Open `demonstration/tokenwise_demo` itself,
trust it, and run **TokenWise: Enable Automatic Context**. Warm the backend before
the presentation. See `demonstation.md` for the complete sequence.

The Python project needs only the standard library; TokenWise's neural backend
still needs its separately installed dependencies and model weights.

## Limits

Local validation: 166 extension tests passed; backend suite 106 tests with 105
passed and one Windows symlink privilege skip; twenty app tests and deterministic
output passed. Packaging includes only the manifest's one project and excludes
private runtime/results. Fresh real-weight and live-cloud results must be
recorded separately; no historical token/CO2 measurements were relabeled.

This remains a Windows-tested beta for trusted local Python repositories.
Selected excerpts are reference data, not necessarily executable source.
Conversation replay is not live chat capture or cross-chat memory. CO2 values
are configured-scenario predictions, not measured cloud emissions or net energy
savings. Recorded older verification results refer to the older fixtures; do not
reuse their exact token counts for this consolidated project.
