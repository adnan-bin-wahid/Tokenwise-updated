# Comparative Study Evidence

Read [comparative_study.md](../../comparative_study.md) for the completed study and
[tests.md](../../tests.md) for functional verification. This folder retains actual
measurements, pins, hashes, evidence decisions, generated tables and report figures.

The successful protocol uses bounded real neural excerpts and separately labeled
retrieval-only/memory ablations. It is not a completed automatic full-file or
Antigravity cloud-answer benchmark. The unsuccessful full-file CPU pilot remains
separate. Do not interpret its post-shutdown connection errors as independent
failures of the other repositories.

Downloaded archives, extracted third-party sources and full packets remain under
ignored `tmp/comparative-study/`, with license metadata retained locally. Upstream
code is not executed. Refer to the exact GitHub commit links for original sources
and their licenses. Counts/hashes in this folder can be shared; they are not a
replacement for the local packets needed for re-scoring.

Run `scripts/run_comparative_study.py`, then `scripts/summarize_comparative_study.py`
with the configured project Python environment to repeat the study. Current results
are overwritten by a new run, so preserve dated records before repeated trials.
