# Context-Only Baseline Lab

Open this folder only for the controlled, pasted-context comparison. Do not
enable TokenWise here. There is deliberately no application source in this
folder. Use three NEW chats with the same task and model, pasting one exported
packet each: all indexed Python code, manually selected code, or TokenWise.

Require the agent to answer from the supplied packet only, without file search,
terminal commands, or editing. Record any tool call as a protocol violation;
the prompt is not a technical sandbox. Compare this with the separate automatic
workflow demonstration in the actual application folders.
